# 인천 GCED 알아보기 — 타임 패스포트: 세계시민 여권을 찾아서

초·중·고 세계시민교육용 비주얼 노벨입니다. 2015년 송도컨벤시아 세계교육포럼의 인천선언에서 출발해 2026년 인천형 세계시민교육까지 시간여행을 합니다. 마지막에는 나만의 **인천세계시민 여권**이 발급됩니다.

## 실행하는 방법
- `index.html` 파일 하나로 실행됩니다. 설치나 로그인이 필요 없습니다.
- 파일을 더블클릭하면 크롬·엣지·웨일에서 바로 열립니다.
- **GitHub Pages로 링크 만들기**
  1. GitHub에서 새 저장소(Public)를 만들고 `index.html`을 업로드합니다.
  2. Settings → Pages → Branch: `main` / `/(root)`를 선택하고 Save를 누릅니다.
  3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속합니다.
- 진행 상황은 브라우저에 자동 저장되고, 이어하기를 할 수 있습니다.
- 학생이 쓴 글은 외부로 전송되지 않습니다.

## 구성 (프롤로그 + 6개 시대, 약 60~90분)
| 시대 | 주요 활동 |
|---|---|
| 프롤로그 | 2026 한마당 전시장에서 시간의 문을 엽니다. |
| 2015 송도 | 인천선언의 비밀을 찾습니다. 세계지도, 선언 조합, 퀴즈를 풉니다. |
| 2019 인천 | 인권·평화·문화다양성·글로벌이슈 워크숍과 다국어 인사, SDGs를 다룹니다. |
| 2021 강화 | 동아시아시민교육, 갈등 해결, 평화 지도를 다룹니다. |
| 2023 인천 속 세계 | 차이나타운·이민사박물관·함박마을·부평 미얀마 마을을 다니며 편견 깨기 활동을 합니다. |
| 2026 세계 속 인천 | 공항·항만·G타워 국제기구·갯벌·매립지를 다니며 지구촌 문제 해결을 다룹니다. |
| 2026 한마당 | AI 정보 검증, 세 가지 다짐 쓰기를 한 뒤 여권이 발급됩니다(인쇄 가능). |

한 차시(40~45분)에 2개 시대씩, 총 3~4차시로 운영하는 것을 권장합니다.

## 교사용 모드
- 타이틀 오른쪽 아래 **교사용 모드**에서 PIN `2015`를 입력합니다.
- 할 수 있는 일: 모든 시대 바로 열기, 기록 초기화, 결과 복사·텍스트 저장, 차시별 토론 질문 보기.
- 교사용 모드에 들어간 뒤에는 새로고침 전까지 모든 미션에 「정답 보고 넘기기」 버튼이 나타납니다.
